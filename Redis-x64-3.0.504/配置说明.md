# Redis配置说明

## Redis位置
- 路径: `Redis-x64-3.0.504`
- 版本: Redis 3.0.504 (Windows x64)
- 配置文件: `redis.windows.conf`

## 连接信息
- 主机: 127.0.0.1
- 端口: 6379
- 密码: 无
- 数据库: 1 (sa-token和缓存使用)

## 自动启动
Redis已集成到项目启动脚本中:
- `start-backend.bat` - 自动检查并启动Redis,然后启动后端
- `一键启动.bat` - 更友好的启动界面
- `stop-all.bat` - 停止所有服务(包括Redis)

## 手动操作
如需手动操作Redis:

### 启动Redis
```cmd
cd "Redis-x64-3.0.504"
redis-server.exe redis.windows.conf
```

### 连接Redis客户端
```cmd
cd "Redis-x64-3.0.504"
redis-cli.exe
```

### 测试连接
```cmd
cd "Redis-x64-3.0.504"
redis-cli.exe ping
```
应返回: PONG

## 注意事项
1. Redis服务会在后台运行,窗口最小化
2. 启动脚本会自动检查Redis是否已运行,避免重复启动
3. 关闭系统时建议使用`stop-all.bat`优雅关闭
