## 📊 脚本功能详解

**功能**: Smart-Admin框架完整初始化脚本

**包含内容**:
- **44张系统表**

  - 系统配置: `t_dict`, `t_dict_data`, `t_config`
  - 日志审计: `t_login_log`, `t_operate_log`, `t_change_log`
  - 业务功能: `t_goods`, `t_category`, `t_file`, `t_feedback`等

- **完整初始数据**
  - 超级管理员账号: `admin / 123456`
  - 默认角色: 超级管理员/部门管理员
  - 系统菜单: 首页/系统设置/组织架构等
  - 字典配置: 性别/状态/类型等

**版本信息**: V3.26 (2024最新版,已包含所有历史升级内容)

**特点**:
- ✅ 已优化为UTF8MB4字符集
- ✅ 包含索引优化
- ✅ 支持逻辑删除
- ✅ 自增ID + 雪花算法混合主键

### 2. SPD系统完整初始化脚本.sql (SPD业务SQL)

**功能**: SPD院内耗材管理系统业务初始化

**执行流程**:
```
第一部分: 数据库创建
  └─ DROP DATABASE smart_admin_v3 (清空旧数据)
  └─ CREATE DATABASE smart_admin_v3 (创建新数据库)
  └─ 设置UTF8MB4字符集

第二部分: 框架表导入
  └─ SOURCE smart_admin_v3.sql (引用框架SQL)

第三部分: SPD业务表创建 (6张表)
  ├─ spd_material (耗材基础表)
  ├─ spd_material_category (耗材分类表)
  ├─ spd_unit (单位维护表)
  ├─ spd_unit_conversion (单位换算关系表)
  ├─ spd_supplier (供应商管理表)
  └─ spd_manufacturer (生产厂家表)

第四部分: 菜单配置 (35个菜单)
  ├─ 一级菜单(7个): SPD耗材管理/采购管理/库存管理等
  └─ 二级菜单(28个): 申领管理/采购单/收货单等

第五部分: 初始数据
  ├─ 单位数据(15条): 个/盒/包/箱/瓶/支/袋/卷/米/克等
  ├─ 分类数据(7条): 耗材/一次性/高值/低值等
  └─ 换算关系(6条): 盒↔个/箱↔盒等
```

**技术特性**:
- 主键策略: 自增ID
- 字符集: UTF8MB4_unicode_ci
- 删除方式: 逻辑删除(del_flag/deleted_flag)
- 多租户: 预留tenant_id字段
- 审计字段: create_by/create_time/update_by/update_time

## ⚙️ 配置说明

### MySQL连接参数

默认配置(可在`初始化数据库.bat`中修改):
```batch
主机: localhost
端口: 3306 (默认)
用户名: root
密码: root
数据库: smart_admin_v3
```

**修改方法**:
1. 右键编辑 `初始化数据库.bat`
2. 找到第22行和第41行的MySQL命令
3. 修改 `-h`(主机) `-u`(用户) `-p`(密码)参数

示例:
```batch
:: 原始命令
mysql -h localhost -u root -proot -e "..."

:: 修改为自定义配置
mysql -h 192.168.1.100 -u spd_user -pSpd@2025 -e "..."
```

---

### 字符集配置

**当前配置**: UTF8MB4 (推荐,完美支持中文和emoji)

**验证方法**:
```sql
-- 查看数据库字符集
SHOW CREATE DATABASE smart_admin_v3;

-- 查看表字符集
SHOW CREATE TABLE spd_material;

-- 应该显示
DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci
```

**如遇中文乱码**,请检查:
1. MySQL配置文件 `my.ini` 是否配置UTF8MB4
2. PowerShell是否使用 `-Encoding UTF8` 参数
3. 数据库连接URL是否包含 `?characterEncoding=utf8mb4`

## ❗ 注意事项

### ⚠️ 数据安全

1. **脚本会删除现有数据库**
   ```sql
   DROP DATABASE IF EXISTS `smart_admin_v3`;
   ```
   - 执行前请确认是否需要备份
   - 建议在全新环境中执行
   - 生产环境请谨慎操作

2. **备份方法**(如有现有数据)
   ```bash
   # 备份整个数据库
   mysqldump -u root -proot smart_admin_v3 > backup_$(date +%Y%m%d_%H%M%S).sql
   
   # 仅备份数据(不含表结构)
   mysqldump -u root -proot --no-create-info smart_admin_v3 > data_backup.sql
   ```

### 🔧 常见问题

**问题1: MySQL连接失败**
```
✗ MySQL连接失败! 请检查MySQL服务是否启动
```

**解决方法**:
1. 检查MySQL服务是否运行
   ```powershell
   # 查看服务状态
   Get-Service -Name MySQL*
   
   # 启动服务
   net start MySQL80
   ```
2. 验证用户名密码
   ```bash
   mysql -u root -proot -e "SELECT 1;"
   ```
3. 检查3306端口是否被占用
   ```powershell
   netstat -ano | findstr :3306
   ```

---

**问题2: SOURCE命令不识别**
```
ERROR: Failed to open file 'smart_admin_v3.sql'
```

**原因**: SOURCE命令仅在MySQL命令行客户端中有效

**解决方法**:
- 使用方式一(一键初始化.bat) ✅
- 使用方式二(PowerShell管道) ✅
- 不要使用方式三的PowerShell管道+SOURCE组合 ❌

---

**问题3: 中文乱码**
```
耗材名称显示为 ?????? 或乱码
```

**解决方法**:
1. 使用UTF8编码读取SQL
   ```powershell
   Get-Content -Encoding UTF8 "SPD系统完整初始化脚本.sql" | mysql ...
   ```
2. 检查MySQL字符集配置
   ```sql
   SHOW VARIABLES LIKE 'character%';
   ```
3. 后端application.yml添加URL参数
   ```yaml
   url: jdbc:mysql://localhost:3306/smart_admin_v3?characterEncoding=utf8mb4&useUnicode=true
   ```

---

**问题4: 菜单不显示**

**原因**: 缓存未刷新或权限未分配

**解决方法**:
1. 清除浏览器缓存(Ctrl+Shift+Delete)
2. 重新登录系统
3. 检查角色权限分配
   ```sql
   -- 为超级管理员分配SPD菜单权限
   SELECT COUNT(*) FROM t_role_menu 
   WHERE role_id = 1 AND menu_id >= 2000 AND menu_id < 3000;
   ```
